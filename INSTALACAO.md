# 📦 Guia de Instalação

## 🎯 Pré-requisitos

1. **Node.js 18.0 ou superior**
2. **npm** (geralmente vem com Node.js)
3. **Token do Bot Discord**

---

## 🚀 Instalação Passo a Passo

### 1. Preparar o Projeto
Extraia o arquivo do bot em uma pasta de sua preferência e abra o terminal nela.

### 2. Instalar Dependências
Execute o comando:
```bash
npm install
```

### 3. Configurar o Arquivo .env
Copie o arquivo de exemplo:
```bash
cp .env.example .env
```
Abra o arquivo `.env` e insira seu **TOKEN**.

### 4. Convidar o Bot
Crie a URL de convite no Portal do Desenvolvedor com os escopos `bot` e `applications.commands` e a permissão `Administrator`.

### 5. Iniciar o Bot
Execute o comando:
```bash
npm start
```

---

## ⚙️ Configuração Inicial

### Whitelist
Use `/whitelist setup` para configurar canais e cargos.

### Tickets
Use `/ticket setup` para configurar o sistema de suporte.

### FiveM
Use `/fivem setup` para monitorar seu servidor.
