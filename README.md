## 📋 Sobre o Projeto

O **Discord Bot Professional** é uma solução completa e robusta para gerenciamento de servidores Discord, especialmente voltada para comunidades de **FiveM/RedM** e servidores que necessitam de sistemas avançados de **Whitelist**, **Tickets** e **Gerenciamento de Staff**.

---

## ✨ Funcionalidades Principais

### 🎯 Sistema de Whitelist
- ✅ Gerenciamento completo de whitelist com Steam ID
- ✅ Painel interativo com botões
- ✅ Aprovação/Rejeição de solicitações
- ✅ Integração com banco de dados SQLite

### 🎫 Sistema de Tickets
- ✅ Categorias personalizáveis
- ✅ Painel de abertura de tickets
- ✅ Sistema de transcrição de conversas
- ✅ Avaliação de atendimento (Rating System)

### 🎮 Integração FiveM/RedM
- ✅ Monitoramento de status do servidor
- ✅ Exibição de jogadores online
- ✅ Atualização automática em tempo real

### 👥 Gerenciamento de Staff
- ✅ Sistema de recrutamento
- ✅ Painel de controle de staff
- ✅ Registro de atividades

---

## 🚀 Instalação

### Passo a Passo

1. **Extraia o projeto:**
   ```bash
   cd discord-bot-professional
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Configure o arquivo `.env`:**
   ```bash
   cp .env.example .env
   ```

4. **Inicie o bot:**
   ```bash
   npm start
   ```
